## 审查问题的处理

- 恢复接口维度，防止 SDK 删除后仍出现覆盖完整的统计。
- 结构化冻结契约参与 outcome/产物判断；错误 route、engine、format、错误码与数量均有反例测试。没有独立页数时不猜测；PDF 的物理页数、输出文件数和 JSON pages 分开；v0.3.1 云端 PDF/video 的 JSON pages 按产物计数，本地 PPTX→PDF 则保留源页计数。
- evaluator v3 使用独立入口；旧版 evaluator 入口保持 v2 判定，历史代码不被新语义覆盖。新版本发布缺少对应结果政策时阻塞，不能自动沿用其他版本的答案。
- R08 的公开接口不支持保留期配置与缺少删除审计分开：前者在获准执行后按版本契约判 failed，后者 blocked；不同 commit 的契约不能复用。
- 正式快照要求完整且已审核的逐页图像 GT，视频还要求五个时间比例位置的独立源页映射；参考缺失、篡改、未审核或不可解码均不能 READY。质量执行前同样检查。
- LibreOffice 路径持久保存；多语言 PPTX 的独立预览在 LibreOffice 失败后使用 Keynote，源文件保持不变。所有候选仍需人工确认。
